# FreshDig for SoundCloud - ストア掲載情報 (Store Listings)

Chrome Web Store および Microsoft Edge Add-ons の各言語向けストアページ掲載情報（タイトル、概要、詳細な説明）のマスターデータです。

---

## 1. 日本語 (Japanese - ja)

### 拡張機能の名前 (Extension Name) [最大45文字]
```text
FreshDig for SoundCloud - 新アーティスト自動発掘
```

### 簡単な説明 / 概要 (Summary / Short Description) [最大132文字]
```text
知ってる曲ゼロ！未試聴の新アーティストだけを連続再生・ワンクリック追加・Dislike除外・浮遊ミニプレイヤー
```

### 詳細な説明 (Detailed Description)
```text
知っている曲は、もう流さない。まだ出会ったことのない新しいアーティストだけを無限にディグする、SoundCloud専用の発掘アシスタント。

【主な機能】
1. 完全未試聴フィルター（Pure Discovery Engine）
過去に「いいね（Like）」した曲や、フォロー中のアーティストの曲を自動スキップ。あなたにとって「100%初めて出会うアーティスト」だけが流れる専用ステーションに生まれ変わります。

2. 秒速の選別（Dislike & Hate フィルター）
- [ 👎 ] Dislike: 「この曲だけ」を二度と流さないよう除外して即座にスキップ。
- [ 🚫 ] Hate: 「この作者の曲すべて」をブラックリストに入れて即座にスキップ。

3. 出会った瞬間にワンクリック保存
- [ ➕ ]: 事前設定したお気に入りプレイリストに一発追加。
- [ ❤️ ]: いいね（Like）。
- [ 🔁 ]: リポスト（Repost）。
- [ 👤＋ ]: アーティストをその場で即フォロー。

4. 浮遊ミニプレイヤー (Picture-in-Picture)
ブラウジング中も画面隅に小さなプレイヤーが常駐。手元ですぐにLikeやプレイリスト追加が可能です。

5. Windows タスクバー連携
タスクバー上のサムネイルから曲名・ジャケット確認や再生/スキップ操作が可能。
```

## 5. Chrome Web Store デベロッパーダッシュボードでの登録手順

1. **[Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole/)** にアクセスします。
2. 対象の拡張機能（FreshDig for SoundCloud）をクリックします。
3. 左メニューの **「ストアの掲載情報 (Store Listing)」** を選択します。
4. 画面上部の **「言語を追加 (Add language)」** をクリックします。
5. ドロップダウンから **「ドイツ語 (German)」** を選択し、上記「3. ドイツ語」の各項目を貼り付けます。
6. 再度 **「言語を追加」** をクリックし、**「ロシア語 (Russian)」** を選択して、上記「4. ロシア語」の各項目を貼り付けます。
7. 画面右上の **「下書きを保存 (Save draft)」** を押し、**「審査に送信 (Submit for review)」** をクリックして完了です。
