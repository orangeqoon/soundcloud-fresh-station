# FreshDig 2.14.1

再生ボタンを押しても再生位置が進まない場合、停止中の曲をスキップして次の曲を再生します。前の曲へ戻って元の曲に戻す復旧処理を置き換えました。

- ミニプレイヤーを閉じず、ページも再読み込みしません。
- 次の曲への移動は1回に限定し、再生位置が進むことを確認します。
- 手動停止・曲変更、ロボット検知、Digによる停止を優先します。
- 同時実行をまとめ、15秒の実行間隔を維持します。
- 次の曲へ移れない場合や再生が進まない場合は復旧を打ち切ります。

検証: Nodeテスト96件、UserScriptビルド、JavaScript構文、ステージ対象パス検査。実機での長時間再生・実音声の確認は未実施です。
