## 必ず直す
1. **名前で除外した作者が効かなくなった（後退）** `freshdig_core.js` の作者判定 `if (!artistId && artist)`。
   曲にはほぼ必ず作者 ID があるので、名前だけで記録された除外（古い記録や ID が取れなかったときの記録。station_hook.js の 2622・2672 付近）が一切当たらなくなった。
   直し方: 名前のキーでも当たりは見る。そのうえで、記録に作者 ID が入っていて曲の作者 ID と違うときだけ外す。古い記録を残すテスト、ID が違う同じ名前を外すテストを `tests/core.test.js` に足す。
2. **返事が無いとき別タブの命令を自分のタブで実行する** station_hook.js の `mpRemoteCall` に足したフォールバック。
   自分のタブで流れている曲は別の曲（または無い）なので、👎 NoPlay・🤬・🤍・🔁・➕・🧐・Follow が**違う曲や作者に効いてしまう**。
   直し方: フォールバックは再生・一時停止（`play`）だけにする。ほかは今までどおり「タブが応答しません」と出すだけにする。
3. **リポストの確認が表示に使われていない** `repostTrackWithCaption`。
   `verified` はログに書くだけで、確認より前に `repostedTrackIds` に入れ「リポストしました」と出している。これでは症状（ミニプレイヤーでは済み、SoundCloud には無い）が直ったか分からない。
   直し方: 確認できたときだけ「済み」にする。確認できなければ `repostedTrackIds` に入れず、「SoundCloud で確認できませんでした」と出してログに残す。
   注意: `ids?limit=50` は新しい順か分からない。50 件より前に入っていると誤って「確認できない」になるので、並び順を確かめるか、`tracks/:id` 側で確かめる方法にする。
4. **版が上がっていない** F2 の修正と見た目の変更 3 回が全部 2.1.0 のまま。4 か所を 2.1.1 にして `.user.js` を作り直す。
5. **進み具合の表のコミット番号が違う** 943089b・011bae6 は存在しない。正しくは F1 が 642f46f、F2 が 0d1bfb6。

## 直したほうがよい
- background.js: `onUpdated` のたびに（題名・音・アイコンが変わるだけでも）`autoDiscardable` を書き直している。`changeInfo.status === 'loading'` のときだけにする。
- **キャプションの送り先が本物か分かっていない** `PUT me/track_reposts/:id/caption` は CLAUDE.md に書いてあるだけで、通信を見て確かめていない（計画の設計 6 では「通信を見て決める」）。ユーザーに 1 回、SoundCloud 本体で一言つきリポストをしてもらい、開発者ツールの通信と比べる。違えば直す。
- 曲名だけの除外キー（`dTracks[title]`・`title_...`）は、同じ題名の別の曲（例「Intro」）も全部飛ばす。曲 ID がある記録では ID だけで判断する。直すのは 1 と同じ形でよい。

## 後で
- `autoDiscardable:false` は「タブを捨てる」のを止めるだけで、Edge の「スリープ中のタブ」（止めておく方）は止めない可能性が高い。実機で直らなければ、Edge の設定「これらのサイトをスリープ状態にしない」に `soundcloud.com` を足すよう、ポップアップかヘルプで案内する。
- 30 秒より長く止まっていたタブは表示の対象から外れる。そのあと再生を押すと、ミニプレイヤーを開いたタブの曲が流れる。同じタブなら問題ない。
