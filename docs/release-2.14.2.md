# FreshDig 2.14.2

Dig ON のステーション再生で、SoundCloudが既に作った再生キューをFreshDigが限定的に整理します。

- 絶対除外条件を先に適用します。
- 残った候補から未試聴曲と作者分散を優先します。
- 同点時はSoundCloud本来の順番を維持します。
- 最大30曲の既存キューだけを対象にします。
- Dig OFF、作者ページ、曲ページ、ロボット検知中は介入しません。
- SoundCloudの推薦APIや候補生成は変更しません。

検証: Nodeテスト97件、UserScriptビルド、構文検査、ステージ対象パス検査。実機の長時間再生は未確認です。
