# FreshDig 2.15.1

- 言語切り替え・表示の不具合を修正:
  - スペイン語・ベトナム語・ルーマニア語の国旗アイコンをSVGベクター画像（`es.svg`, `vi.svg`, `ro.svg`）として追加・配備（Windows環境での絵文字文字化け・崩れを解消）。
  - ポップアップのヘッダーレイアウトを整理し、国旗ボタン列を独立して綺麗に並べ、ステータスバッジの文字省略・圧迫を解消。
  - ルーマニア語（ro）選択時に「既聴曲履歴」ボタンが英語（Heard history）にフォールバックしていた不具合を修正。
  - ポップアップ初期表示時の翻訳適用タイミングを改善し、読み込み中の日本語残留を解消。
  - SoundCloudタブ側でストレージ同期を受け取った際に `applyLanguage()` を即座に適用するよう修正（ミニプレイヤー・ボタンツールチップの多言語反映を強化）。
  - ガイド画面（`guide.js`）およびリスト管理画面（`lists.js`）で言語を変更した際に `chrome.storage.local` へ正しく永続化されるよう修正。
