# FreshDig 2.14.11

- キーボードショートカット機能を追加（`Alt+Key`, `Alt+Shift+Key` による再生・一時停止、次へ、前へ、Like、後で聴く、Dislike、Hate操作）。
- ポップアップ画面にショートカットキーの設定UIおよび設定コピー機能を追加。
- ミニプレイヤー（Picture-in-Picture）のリモート同期（`mpUseRemote`）を強化。ハートビート停止時でもリモートプレイヤーへの適切な操作ルーティングを維持。
- 再生位置が進まない停止時の自動リカバリを改善（2秒進捗チェックの確実化、再生失敗イベント発生時にも次曲へ遷移して再生を継続）。
- ドキュメントおよびREADMEの説明文を最新の設計に合わせて整理・明確化。
