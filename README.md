# SoundCloud Fresh Station & Follower Stream (Edge / Chrome Extension)

SoundCloudのステーションおよびストリーム（タイムライン）再生を強化するブラウザ拡張機能（Manifest V3対応）およびユーザースクリプトです。

## 主な機能

1. **🎛️ 2つの再生動作モード**
   - **🔍 未知の曲発掘（Discovery モード）**
     - ステーション再生時に「いいね済みの曲（Likes）」「フォロー中アーティスト」「Dislike曲」「Hate作者」を自動排除。
     - まだ知らない新しいアーティスト・未知の音楽だけをエンドレスに流します。
     - **マージン付き安全スキップ**: 曲が切り替わってから1.2秒の安定マージンを待って判定・スキップするため、誤爆やループなしにスムーズに未知曲だけが流れます。
   - **👥 フォロー中の新曲のみ（Following Only モード）**
     - 他人のリポスト（Repost）を完全シャットアウト。
     - 自分がフォローしているアーティスト本人が新しく直接アップロードした新曲のみを抽出して連続再生します。

2. **下部プレイヤー直結の3連スマートアクションボタン**
   - 再生バー左側（曲名アートワーク・公式Likeボタンのすぐ右隣）にコンパクトなアイコン（26×26px）で配置：
     - **`[ 👎 ]` Dislike ボタン**: **「この曲だけ」** を二度と流れないよう除外して、即座に次の曲へスキップ（1クリック・ダイアログなし）。
     - **`[ 🚫 ]` Hate ボタン**: **「この作者の全楽曲」** を今後一切流さないよう除外して、即座に次の曲へスキップ（1クリック・ダイアログなし）。
     - **`[ ➕ ]` プレイリスト一発追加ボタン**: 現在再生中の曲を、設定中のターゲットプレイリストに即座に追加（追加中は `⏳`、完了すると `✅` に変化。右クリックで保存先変更）。

3. **⚙️ 設定ポップアップ & 即時同期**
   - 拡張機能アイコンをクリックすると、除外中の「アーティスト」「ジャンル」「曲」の一覧を確認・個別解除できます。
   - **「🔄 今すぐ同期」ボタン** により、SoundCloudアカウントの最新プレイリストやライク一覧をいつでもワンタップで再同期可能。

## インストール手順

### Microsoft Edge / Google Chrome
1. 本リポジトリをZIPダウンロードまたはクローンします。
2. ブラウザで `edge://extensions` または `chrome://extensions` を開きます。
3. **「開発者モード」** を ON にします。
4. **「展開して読み込む」**（または「パッケージ化されていない拡張機能を読み込む」）をクリックし、本フォルダを選択します。

### Tampermonkey をご利用の場合
- `soundcloud_fresh_station.user.js` をTampermonkeyにインポートすることで、同様のフック機能を利用できます。
