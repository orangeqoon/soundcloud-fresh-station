# FreshDig for SoundCloud

> 🌐 日本語 | [English](docs/readme/README.en.md) | [Deutsch](docs/readme/README.de.md) | [Русский](docs/readme/README.ru.md) | [Español](docs/readme/README.es.md) | [Tiếng Việt](docs/readme/README.vi.md)

FreshDigは、SoundCloudのステーションを自分の発掘ルールで整理するEdge / Chrome拡張機能です。Dig ONにすると、Like済み曲、Follow中作者、不再生曲、除外作者などをスキップし、残ったキューから未試聴曲と作者の分散を優先します。

## 解決する問題

SoundCloudのステーションでは、知っている曲や避けたい作者が再び混ざることがあります。FreshDigはSoundCloudの推薦自体を変更せず、返された候補と再生キューにローカルの除外・保存・既聴ルールを適用して、次に聴く曲を整理します。

## 主な機能

- **Digモード**：Like済み曲、Follow中作者、不再生曲、後で聴く人、除外作者・ジャンルを検知してスキップし、未試聴曲と作者の分散を優先
- **一度でも聴いた曲を飛ばす**：Dig設定でオンにした場合だけ、実際に10秒再生した曲を記録して次回からスキップ（初期状態はオフ）
- **Dislike / Hate**：曲単位または作者単位で除外
- **後で聴く人リスト**：作者を保存し、拡張機能のアイコンから作者のトラックページを開く
- **ミニプレイヤー**：別ウィンドウで再生、次へ、音量、プレイリスト追加、Like、Repost、Follow、除外を操作
- **リストのバックアップ**：後で聴く人・不再生の曲・作者除外・ジャンル除外の4リストをMarkdownで書き出し、JSONから復元
- **不具合レポート**：再生停止などを調べるためのローカル診断レポートを保存

## 「一度でも聴いた曲を飛ばす」の記録方法

この設定は初期状態ではオフです。オンにすると、実際の再生時間を累計し、10秒以上再生した曲をID単位で記録します。10秒未満の短い曲は、ほぼ全体を再生して自然終了した場合に記録します。シークで飛ばした時間や一時停止は加算しません。記録した現在の再生は継続し、次回のDig再生からスキップします。作者のトラックページなどを直接開いて聴く場合は、そのページでの再生を優先します。

拡張機能版は拡張機能専用IndexedDBに曲IDと初回記録日時だけを保持します。判定キャッシュは既聴・未記録それぞれ最大2,000件で、全履歴をメモリに読み込みません。旧ページ側の履歴は少量ずつ移行し、旧データを勝手に削除しません。UserScript版は引き続きSoundCloudページ側IndexedDBを使用します。保存できない場合は通知し、保存成功を装いません。

拡張機能アイコンの「既聴曲履歴 / バックアップ」から件数確認、JSON書き出し、追加読み込み、履歴削除ができます。別PCへはバックアップの全パートを渡して読み込んでください。既存の4リスト用バックアップとは別形式です。大量履歴は5,000件ずつ分割され、複数ファイルのダウンロード許可が必要な場合があります。Google Driveなどへの自動同期はまだ行いません。

再生ボタンを押しても再生位置が進まない場合は、その曲をスキップして次の曲の再生を試みます。前の曲に戻ったり、ミニプレイヤーを閉じたり、ページを自動再読み込みしたりしません。手動で停止・曲変更した場合は復旧を中止します。復旧中はDigの自動スキップを一時停止し、終了後は通常の判定に戻ります。15秒の実行間隔を設け、次の曲も再生できなければ続けて曲を飛ばしません。

## データとプライバシー

FreshDigの設定、リスト、聞いた曲の記録はブラウザ内に保存されます。FreshDig独自の分析サーバーや広告用の外部送信は行いません。Like、Follow、Repost、プレイリスト追加などの操作では、SoundCloudアカウントを操作するためSoundCloudとの通信が発生します。

既聴履歴を長期保持するため `unlimitedStorage` を使用します。これはローカルの保存容量・自動退避対策のためであり、閲覧対象サイトや外部送信先を増やす権限ではありません。詳細は[データ取り扱い方針](PRIVACY.md)をご確認ください。

## インストール

1. `edge://extensions` または `chrome://extensions` を開く
2. 開発者モードを有効にする
3. 「展開して読み込む」で拡張機能フォルダーを選ぶ

Tampermonkeyでは、リポジトリの `soundcloud_fresh_station.user.js` を読み込めます。
